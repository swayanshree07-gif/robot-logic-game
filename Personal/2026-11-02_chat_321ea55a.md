- **Name and theme (my choice):** the game is "Night Shift at Ferrolab". The robot is called Pip, and the language is Cog: one command per line, with blocks closed by `end`.

- **World (`src/world/`):** walls, goal pads, parts that Pip can pick up and drop, and bins to deliver them to. There are 7 sensors and two kinds of goal (reach the pad, or deliver all parts).
- **Levels:** 5 trial levels, each with a solution the tests run and require to win.
- **Prototype page:** you pick a level, write a program, and use Run, Step or Reset. All the art is drawn in code, and your program for each level is saved in localStorage.

**Rule I set:** a run ends as soon as Pip reaches the goal, even if the program has more lines. One of my tests first expected an overshooting program to fail; I changed the test to match this rule. It's noted in `PROGRESS.md`.
